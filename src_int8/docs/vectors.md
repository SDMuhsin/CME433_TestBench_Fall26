# Golden vectors for the RTL team

Generated by `python3 -m src_int8.golden.vectors <out_dir>` from the shipped parameters
(`golden/params/mamba_e96_int8.npz`); `--story "..."` (repeatable) selects other stories,
`--params` another parameter set (e.g. a random one that passes the exporter asserts). Every
number is produced by the bit-exact integer golden (`src_int8/golden/`), so the RTL must match
each file bit for bit. All files are plain text, one record per line, hex, two's complement in
the stated width, little-endian byte order where bytes are listed.

## Chip vectors (`<out_dir>/chip/`)

The default run has 2 stories, 31 tokens ("Once upon a time", "Lily saw a dog."). Each story
starts from zero state: the host issues `CTRL.STATE_RESET` before its first byte.

| File | Record | Per token | Contents |
|---|---|---|---|
| `plan.memh` | 3 hex digits | 1 | bit 8 = state reset before this token, bits 7..0 = the input byte |
| `stream.memh` | 2 hex digits (1 byte) | 54,280 | the token's weight stream in host order (spec section 7), `token_stream()` |
| `logits.memh` | 4 hex digits (INT16) | 128 | expected logits, Q7.8, index v = byte value; the chip stores them LE at host 0x1040 |
| `h.memh` | 6 hex digits (INT24) | 768 | SSM state after the token: H0 then H1, entry index = 4 d + n (spec section 6), Q6.17 |
| `conv.memh` | 2 hex digits (INT8) | 192 | CONV0 then CONV1 after the token (= this token's `xi` of each block) |
| `host.memh` | 2 hex digits | 4,608 (0x1200) | the host read-back image after the token: H entries as 4-byte LE slots at 0x0000 (byte 3 = 0), BMEM at 0x1000 (XN region undefined -> 0, LOGITS at 0x1040, CONV0 at 0x1140, CONV1 at 0x11A0) |

Token k of the run uses lines `[k * N, (k + 1) * N)` of each per-token file. The chip TB compares
the 128 logits after every token and, at least at the end of each story, the H and CONV state
through `RD_MEM[_Q]`. Only the LOGITS, CONV0 and CONV1 bytes of `host.memh`'s BMEM part are
defined; XN, X, U, DBC and TMP are scratch (`X..TMP` is overwritten by the logits).

## Unit vectors (`<out_dir>/unit/`)

| File | Record (space separated hex) | Records | Covers |
|---|---|---|---|
| `lane.hex` | `K ps a[0..K-1] b[0..K-1] acc` (2, 1, 6 x K, 4 x K, 8 digits) | 2,000 | `acc = sum_k rsh(a_k * b_k, ps)`, K 1..128, ps in {0, 4, 6, 11, 15}; INT8 x INT8 at ps 0, full INT24 x INT16 otherwise |
| `wb.hex` | `mode acc M s sh addend w out` (1, 8, 4, 2, 2, 4, 2, 8 digits) | 20,000 | mode 0: `sat_w(rsh(acc, sh) + addend)`; mode 1: `sat_w(((acc * M + 2^(s-1)) >> s) + addend)`; w in {08, 10, 18}; includes every power-of-two acc and the saturation edges |
| `nlu.hex` | `fn x i f shfn zero y` (1, 8, 3, 3, 2, 1, 4 digits) | 51,000 | fn 0 sigmoid / 1 softplus: every x in [-2200, 2200) (clamp both sides); 2 exp2: boundaries (0, -1, -2^19 +- 1, -16 * 2^19 +- 1, -2^31, positive) + 20,000 random; 3 rsqrt: boundaries (16, 2^16, 2^17, 2^18, 2^31 - 1) + 22,000 random. `i` = ROM word of the left grid point, `f` = fraction (0..0x800), `shfn` = writeback shift, `zero` = exp2 zero flag, `y` = `sh_16(T[i] (2^11 - f) + T[i+1] f, shfn)` (0 when `zero`) |

The ROM itself is `golden/params/nlu_rom.hex` (340 lines, 4 hex digits) and the generated RTL
`rtl/nonlin/mq_nlu_rom.v` / `mq_nlu_defs.vh` (`python3 -m src_int8.scripts.gen_nlu_rom`).

## Other collateral

- `golden/params/mamba_e96_int8.npz`: the shipped integer parameters (`golden/io/params.py`
  describes the keys); `golden/io/stream.py` builds the 54,280-byte stream and
  `golden/io/memmap.py` has the address map and the host image builder.
- The state-safe abort window is `golden.io.stream.state_safe_bytes(cfg)` = 197 B (spec section 8).
- Random legal parameter sets for early RTL bring-up: `golden/tests/conftest.py::random_params`.
